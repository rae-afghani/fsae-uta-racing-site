Section Templates

Sama, open a template, copy its HTML, and paste it into the page where you want the section to appear.

How to add a section
  1. Open the page’s HTML file and find its <main> area. Paste the copied section between two existing sections.
  2. Keep the data-template attribute. It tells the JavaScript which section needs buttons or animation.
  3. The shared stylesheet is /site.css. For counters, hotspots, the timeline, or the sponsor marquee, load /scripts/sections.js with defer in the page head. The hero and intro use /scripts/hero.js instead. Load each script once per page.
  4. Save and preview the page. Add your own unique section id if you want to link directly to it.
